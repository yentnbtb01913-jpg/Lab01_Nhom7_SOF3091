# Tiêu chí Phần D – Lab 3

**Tên:** Chụp ảnh khi test thất bại

**Tỷ trọng:** 15%

**Nguồn:** `Lab3/DeBai.pdf` — mục 2, Phần D.

## Nguyên văn tiêu chí theo đề

```text
Phần D — Chụp ảnh khi test thất bại (15%)

 • Thêm cơ chế chụp ảnh vào [TearDown], CHỈ chụp khi Outcome.Status ==
   TestStatus.Failed.
 • Đặt tên file ảnh theo tên ca test; đính kèm bằng
   TestContext.AddTestAttachment(path).
 • Cố ý làm 1 test rớt để sinh ảnh; nộp kèm ảnh đó làm minh chứng.
```
